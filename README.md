A simple Python project that connects to a MySQL database, runs sales summary queries using SQL, and visualizes the results with bar charts.
# 📊 Basic Sales Summary using Python, MySQL, and Matplotlib
![content type by rating](https://github.com/SuhailIsmail/Task-7/blob/main/Sales_chart.png?raw=True)

This project demonstrates how to connect Python to a MySQL database using `pymysql`, run basic SQL queries for sales data, and visualize the results using `matplotlib`.

---

## 🧰 Tools & Libraries Used
- Python 3
- MySQL
- `pymysql`
- `pandas`
- `matplotlib`
- (Optional) `tabulate` for better console tables

---

## 📁 Features
- Connects to a MySQL database
- Creates a basic `sales` table (if not exists) and inserts sample data
- Runs SQL queries to calculate:
  - Total quantity sold and revenue per product
  - Daily revenue summary
- Displays results using `print()` and `pandas`
- Plots simple bar charts using `matplotlib`
